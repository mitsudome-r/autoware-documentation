# Urban robotaxi

The urban robotaxi family covers passenger transport in urban areas, within a defined ODD.

| Field       | Value                              |
| ----------- | ---------------------------------- |
| Application | Passenger transport in urban areas |
| Guideline   | Planned, in a new repository       |
| Status      | Proposed                           |

## Fusion Pilot robotaxi

The first reference design uses the [Fusion Pilot](../software-stacks.md#fusion-pilot) stack.

### Deployment profile

| Part                 | Target                                        |
| -------------------- | --------------------------------------------- |
| Vehicle platform     | A passenger vehicle with cameras and LiDARs   |
| Operating conditions | Urban roads. The ODD is not specified yet.    |
| Use case             | Point-to-point, on-demand passenger transport |

The sensor configuration and the ODD are not specified yet.
